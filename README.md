# 🐾 PetCare Clinic System

## 📌 Project Overview

PetCare Clinic System is a veterinary clinic management web application designed to replace traditional paper records and make it easier for clinic staff to manage and track pet patients.

The system provides a simple and interactive interface for managing pet information and keeping track of their medical and care records.

---

## 🎯 Project Goal

The main goal of this project is to simplify veterinary clinic management by organizing pet records digitally instead of relying on paper-based records.

It allows clinic staff to quickly add, view, search, update, and delete pet records.

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Database
- SQLite

---

## ✨ Key Features

### 🐶 Patient Management
- Add new pet records.
- View all registered pets.
- Search for pets by name.
- Edit existing pet information.
- Delete pet records.

### 💊 Medical & Care Tracking
- Add medication information.
- Record dosage and medication dates.
- Track basic medical care information.

### 📊 Statistics
- Display the total number of registered pets.
- Show pet statistics by type.

### ⚡ Dynamic Interface
- Interactive and user-friendly interface.
- Data is updated dynamically using JavaScript.
- Communication between the frontend and backend using API requests.
